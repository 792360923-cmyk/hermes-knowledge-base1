# 总指挥复查9项指标——任何一项不通过=需返工

## 规则结论

最终交付前，Commander必须输出9项复查指标。只要有一项"不通过"，最终状态必须是"需返工"。

## 9项复查指标

```
【总指挥复查结果】
- 数据真实性：通过 / 不通过
- 字段完整性：通过 / 不通过
- 分类准确性：通过 / 不通过
- 公式准确性：通过 / 不通过
- 分析深度：通过 / 不通过
- 结论可靠性：通过 / 不通过
- 来源标注：通过 / 不通过
- 是否发现偷懒：是 / 否
- 是否发现编造：是 / 否
- 需要返工的问题：1. 2. 3.
- 修正动作：1. 2. 3.
- 最终状态：可交付 / 需返工
```

## 错误表现

1. 复查只写"通过"不写依据
2. 发现编造只标记不返工
3. "是否发现偷懒：是"但最终状态仍写"可交付"
4. 复查发现问题继续交付不告知用户

## 正确做法

- 每一项都要写通过/不通过 + 简要说明
- 发现编造 → 整页重做
- 发现分类错 → 重新统计
- 发现单位错 → 重新换算
- 发现公式错 → 重新计算
- 最终状态必须诚实反映是否可交付

## 适用场景

所有Amazon调研任务的最终交付前。
