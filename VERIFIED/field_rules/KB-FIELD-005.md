# 所有字段必须量化——不能笼统写"容量大""功率高"

## 规则结论

所有字段必须量化到具体数值。禁止用"大/高/强/长/快/轻/静"等模糊形容词替代数据。

## 强制量化清单

| 笼统写法 | 必须量化为 |
|----------|-----------|
| 容量大 | 具体 ml/L/mAh |
| 功率高 | 具体 W |
| 续航长 | 具体分钟/小时 |
| 噪音低 | 具体 dB |
| 轻便 | 具体 g/kg |
| 快充 | 充电时间和接口方式 |
| 宽电压 | 具体 110V/120V/220V/110-240V |
| 充电快 | 具体充电时间（如2h充满） |
| 风量大 | 具体 CFM/L/min |
| 压力高 | 具体 PSI/Bar |

## 错误表现

1. 填"容量大"而不写具体ml/L
2. 填"续航时间长"而不写具体小时
3. 填"快充"而不写充电时间和接口
4. 填"低噪音"而不写dB值
5. 吹叶机：CFM写"大风量"（应该650CFM/880CFM）

## 正确做法

- 每个量化字段都必须有具体数值
- 无法从页面获取具体数值时 → 填"未标注"而不是"容量大"
- 容量 → ml/L/mAh
- 功率 → W
- 电压 → V
- 噪音 → dB
- 重量 → g/kg

## 适用场景

所有产品参数提取。

## 禁止再犯

是。

## 来源证据

- 威猛先生宪法铁律78-91
- Bike Pumps调研：L/min、克重、mAh、PSI全部具体数值
