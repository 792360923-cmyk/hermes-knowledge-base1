# 错误黑名单格式——每犯错生成短规则

## 规则结论

每次Hermes犯错后，必须生成一条短错误规则，格式如下：

```
错误：具体错误描述
正确做法：正确的做法
适用场景：什么类目/任务
禁止再犯：是/否
来源：用户纠正 / Commander复查
```

## 用途

- 存入PENDING（待审核区）供用户审核
- 下次同类任务时作为"错误修正模式"读取1-3条
- 防止重复犯同类错误

## 示例

```
错误：把2-in-1蒸汽熨斗作为产品主分类。
正确做法：2-in-1是功能标签，主分类必须按结构分为手持式/旋转式/宽压式等。
适用场景：挂烫机/蒸汽熨斗类目。
禁止再犯：是。
来源：用户纠正。
```

## 适用场景

任何犯错的场景。优先记录"防止再次犯错"的内容。

## 禁止再犯

是。
