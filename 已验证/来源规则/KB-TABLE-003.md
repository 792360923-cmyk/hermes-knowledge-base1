# 结论必须有数据+占比+原因+影响+建议

## 规则结论

所有分析结论必须包含五个要素：数据、占比、原因、影响、建议。禁止空话套话。结论必须含"做/不做"决策。

## 结论五要素

1. **数据**：具体数字（如"月销10,465"）
2. **占比**：统计占比（如"占76%""渗透率26%"）
3. **原因**：为什么（如"CFM是最强定价因子"）
4. **影响**：对选品/定价/listing的影响
5. **建议**：做/不做 + 什么方向 + 定价 + 核心配置

## 禁止空话

| 禁止 | 替代表达 |
|------|---------|
| 市场不错 | 50产品月销9万+，月销售额$810万 |
| 竞争激烈 | Top3品牌占47%，2025年33个新品涌入 |
| 有机会 | 无刷渗透26%，$69-89仅2个产品，空档明确 |
| 建议优化产品 | 做$79无线无刷+2×5.0Ah+Type-C+<68dB |
| 用户关注质量 | 差评TOP3：续航不足35%/噪音超预期20%/重量15% |

## 错误表现

1. "这个类目市场不错"（没有数据）
2. "竞争比较激烈"（没有占比）
3. "产品差异化不够"（没有说明差在哪）
4. 只描述现象不解释原因
5. 只列数据不输出判断
6. 结论没有"做/不做"决策

## 正确示例

- ✅ "无刷电机渗透率26%，处于成长期（10-30%），$69-89仅2个产品——$35-45无刷+Type-C是当前最大切入空档。建议做$39.99无刷迷你电动打气泵(27L/min+136g+Type-C+双阀)。不做$20以下有刷(红海无利润)。"

## 适用场景

所有Amazon产品调研的分析结论部分。
