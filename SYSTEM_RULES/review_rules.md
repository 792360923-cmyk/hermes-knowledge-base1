# 复查与交付规则

## 结论

所有 Amazon 任务最终交付前必须经过 Commander 复查，9 项指标全部通过才可交付。任何一项"不通过"，最终状态必须是"需返工"。

## 复查铁律 (131-150)

- 未经 Commander 复查，禁止交付
- 未经 Data Verifier 验证，禁止交付
- 每一页必须单独验收，必须有通过/不通过结论
- 不通过必须返工，返工后必须二次复查

**发现以下问题必须对应处理：**
- 编造 → 整页重做
- 分类错 → 重新统计
- 单位错 → 重新换算
- 公式错 → 重新计算
- 来源缺失 → 补来源
- 字段笼统 → 拆细
- 结论空泛 → 重写
- 截图缺失 → 补证据


## 交付铁律 (151-170)

最终交付必须包含：
1. 数据来源说明
2. 字段规则说明
3. 分类规则说明
4. 核心统计
5. 关键发现
6. 风险提醒
7. 行动建议
8. 总指挥复查结果

**禁止：**
- 只交表格不解释
- 只给结论不依据
- 只给分析不来源
- 草稿当最终稿
- 未核验内容进交付
- 隐藏不确定项
- 删除异常值不说明
- 改动原始数据不标注
- 遗漏用户明确要求

## 质量铁律 (171-190)

- 表格必须整洁，字段名统一，表头清晰
- 数字格式统一，空值/异常值必须标注
- 公式可追溯，图表有标题/单位/对应数据源
- 不能为了好看牺牲准确
- 不能为了速度牺牲核验
- 不能为了完整而编造

## 最终底线 (191-200)

191. 不知道就说不知道
192. 看不清就说看不清
193. 没找到就说没找到
194. 没标注就写未标注
195. 有冲突就写待核实
196. 有风险就必须提示
197. 有异常就必须标记
198. 有错误就必须返工
199. 有来源才可确认
200. 有复查才可交付
