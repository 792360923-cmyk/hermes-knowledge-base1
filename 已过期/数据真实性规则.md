# 数据真实性规则

## 结论

所有数字类数据必须有来源。没有来源时必须写 Unknown / 未标注 / 待核实。禁止用"大概""估计""应该""可能是"替代真实数据。

## 数据铁律 (11-30)

所有以下字段，没有来源一律 Unknown/未标注/待核实：
- 销量、搜索量、BSR、市场规模、价格、评分、评论数
- Coupon、FBA费用、ABA排名、PPC竞价、转化率、点击率
- 利润率、品牌占比、类目占比
- 趋势判断 → 待核实

**禁止：**
- 用 AI 经验补数据
- 用行业常识替代真实数据

## 来源铁律 (31-40)

来源必须具体到：
- Amazon 标题、五点、Product Overview、图片、A+、Review、Q&A
- 卖家精灵、Keepa、用户提供文件

**禁止：**
- 只写"网络"或"亚马逊"作为来源
- 套用别的 ASIN 数据
- 混淆父体/子体数据
- 把类目数据当单品数据
- 把样本数据说成全市场数据

## 分类铁律 (41-60)

- 按产品结构分类，不按营销词分类
- 功能词/2-in-1/Portable/Upgrade/Pro 不能当主分类
- 配件不能归为整机，套装必须判断是否含主机
- 图片与标题冲突 → 待核实
- 每个产品只能有一个主分类
- "其他"占比 > 10% → 必须重新分类
- "待核实"占比 > 10% → 必须补查来源

## 字段铁律 (61-91)

**禁止笼统填写示例：**

| 笼统写法 | 必须细化为 |
|----------|-----------|
| USB | Type-C / Micro USB / Lightning / 磁吸 / 触点 / 充电盒 / 接口未确认 |
| 电池 | 锂电池 / 铅酸电池 / 干电池 / 纽扣电池 / 未标注 |
| 遥控 | 遥控器 / APP / 蓝牙 / WiFi / 2.4G / 触控 / 按键 |
| 防水 | IPX4 / IPX5 / IPX6 / IPX7 / IP67 / 未标注 |
| 材质 | ABS / PP / PC / 不锈钢 / 铝合金 / 硅胶 / 玻璃 / 陶瓷 |
| 容量 | 具体 ml / L / mAh |
| 功率 | 具体 W |
| 噪音 | 具体 dB |

## 单位铁律 (92-110)

| 类别 | 统一单位 |
|------|---------|
| 重量 | g / kg |
| 容量 | ml / L / mAh |
| 尺寸 | cm / inch |
| 价格 | USD |
| 功率 | W |
| 电压 | V |
| 时间 | 秒 / 分钟 / 小时 |
| 占比 | % |

不同单位必须换算，禁止混用。

## 禁止误用

- 禁止把 Class BSR 和 Subcategory BSR 混用
- 禁止把父体销量和子体销量混用
- 禁止把当前价格和 Coupon 后价格混用
- 禁止把 USD 和 RMB 混用不标注汇率
