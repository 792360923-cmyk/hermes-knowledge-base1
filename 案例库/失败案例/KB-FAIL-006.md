# Grill Brushes 调研偷懒——中文标题缺30条/分类"通用"兜底/场景词误判/关键词误匹配/没问Alexa

## 错误表现（5个偷懒点，一次任务全踩）

威猛先生2026-08-25做 Grill Brushes（烧烤刷）BSR前100第2页分析时，指出"铁律不准偷懒，中文标题没有、分类不够详细、有没有严格按skill"。逐项核查，发现5个偷懒点：

1. **中文标题缺30条**：卖家精灵导出里"标题(翻译)"字段30条为空，直接留空没补生成。违反"中文标题100条完整翻译"铁律。
2. **分类用"通用"兜底**：写了 `烧烤刷(通用)` 兜底类，占了38%，违反"最大类<50%且不能用'通用'兜底"。
3. **场景词误判成产品类型**：把五点里"for cast iron"（适用于铸铁烤架，是使用场景）误判成"铸铁清洁刷"产品类型，导致10件被错误归类。
4. **关键词子串误匹配**：`('light','LED灯')` 把 "lightweight"、"FlexTexture" 里的 "light" 子串误判成LED灯，Scrub Daddy 标题被错误加上"LED灯"。
5. **竞品没问Alexa**：电动烧烤刷竞品（Leebein/drayvorx）的电机转速/电池容量/充电接口/防水等级，没问Alexa核实，直接留空。

## 错误原因

1. 中文标题：只依赖卖家精灵"标题(翻译)"字段，该字段为空时没有 fallback 生成逻辑。
2. 分类兜底：为省事写了"通用"类，没有把刷头结构（刮刀+刷/纯刷毛/无刷毛/螺旋/尼龙）彻底拆开。
3. 场景词误判：`cast iron` 在标题是类型、在五点是场景，用了"标题OR五点都搜"的宽松匹配，没区分上下文。
4. 词边界：关键词提取没用 `\b` 词边界，`light` 命中 `lightweight`/`light-weight` 子串。
5. Alexa：只核验了部分竞品，电动类竞品的专属字段（电机/电池/充电/防水）漏核。

## 正确做法

1. **中文标题必须有 fallback**：卖家精灵"标题(翻译)"为空时，用"品牌+核心功能+刷头结构+材质+尺寸"公式逐条生成，100条不允许留空。
2. **禁止"通用"兜底**：分类必须拆到物理结构层（刮刀+刷组合/无刷毛刷/刷毛刷/螺旋刷/尼龙刷毛刷/电动/蒸汽），兜底类占比必须 < 10% 或为0。
3. **场景词 vs 类型词区分**：`cast iron` 只在标题明确写 "Cast Iron Brush" 才算类型；五点里 "for cast iron" 是使用场景，归入"适用烤架"场景列，不当产品类型。
4. **关键词提取用词边界**：`light` 必须用 `re.search(r'\bled light\b')` 或精确词组 "led light"/"built-in light"，不能用子串 `in` 匹配。
5. **电动竞品必问Alexa**：凡是电动/带电产品，电机转速(RPM)/电池容量(mAh)/充电接口(Type-C还是Micro)/防水等级，必须逐ASIN问Alexa核实，答不出标"未标注"。

## 后果

- 中文标题30条空白，表格交付不完整
- 分类"通用"占38%，无法做有意义的类型占比分析
- "铸铁清洁刷"10件是虚高的假分类，实际只有1件(OXO)
- Scrub Daddy 被误标"LED灯"，差异化分析失真
- 电动竞品的核心参数缺失，切入建议缺乏数据支撑

## 适用场景

所有 Amazon BSR 产品调研、中文标题生成、产品主分类、关键词/字段提取、带电产品竞品核实。

## 教训

"铁律不准偷懒"是底线。中文标题、分类细分、字段提取、Alexa核实四件事任何一件偷懒，都会被威猛先生一眼看穿返工。做之前先过一遍 skill 的"提取后自检清单"。
