# String Trimmers 调研偷懒——电压兜底/竞品核验不全/图片缺失/无交叉验证/分类未核实

## 错误表现（5个偷懒点）

1. **"电池款"兜底22件**：电压未从标题或品牌生态识别出来的产品全部归了"电池款"兜底类，占比22%，超过10%铁律。没逐个爬Amazon详情页补电压。
2. **6个竞品只核了3个**：承诺全部逐ASIN Alexa核实，实际只核了WORX/EGO/KOMASTY 3个，HortiHub/BLACK+DECKER 40V/EGO Pro没核。
3. **图片缺11张**：100张只下了89张，没补。
4. **没做交叉验证**：Alexa核出的电压/电机/电池数据，没有回头和卖家精灵的详细参数列做对比验证。
5. **没有逐ASIN核实电动/燃油分类**：22件"电池款"和8件"燃油款"靠标题关键词推断，没问Alexa确认。

## 错误原因

1. 兜底类：电压提取不完善，选择了"兜底"而不是去补数据。
2. 竞品核验：核了3个后急于建表输出结论，放弃继续核验。
3. 图片：下载失败后没重试。
4. 交叉验证：对Alexa结果过度信任，没做二次来源核对。
5. 分类核实：觉得"标题明确写electric/gas"就够，没问Alexa。

## 正确做法

1. **兜底类必须<10%**：电压识别失败必须去Amazon参数表或Alexa补全。
2. **竞品全核**：选定几个核几个，不能偷工减料。
3. **图片全量**：下载失败重试，换URL源。
4. **交叉验证铁律**：Alexa结果必须和卖家精灵详细参数做三方交叉验证。
5. **电动/燃油必问Alexa**：逐ASIN问"is this electric powered or gas powered?"

## 后果

- 22件产品电压不明，分类不准确
- 竞品参数不完整，切入建议缺乏数据支撑
- 表格不完整（缺图）
- 无交叉验证可能存在不一致

## 适用场景

所有Amazon BSR产品调研，尤其涉及电池/电动/燃油等带电产品分类。

## 教训

"偷懒"是致命缺陷。兜底类、竞品核验缩水、不交叉验证——任何一点都会导致返工+记录失败案例。
