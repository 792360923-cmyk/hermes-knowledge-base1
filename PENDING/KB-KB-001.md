# 知识库四级读取模式——默认只注常驻短规则

## 规则结论

知识库不是每次都全量读取，而是按需读取。四种模式逐级加载，默认模式最轻量。

## 四级读取模式

| 模式 | 触发条件 | 读取内容 |
|------|---------|---------|
| 默认模式 | 新类目/简单任务 | 只注入10条常驻短规则 |
| 重复类目模式 | 同类目任务 | 常驻短规则 + INDEX + 3-5条知识卡 |
| 错误修正模式 | 正在纠错 | 常驻短规则 + 1-3条failure案例 |
| 重大调研模式 | 9页产品调研 | 常驻短规则 + INDEX + 5条知识卡 + 3条failure |

## 10条常驻短规则

1. 禁止编造数据，无来源写Unknown/未标注/待核实
2. 禁止偷懒，字段能细分必须细分
3. 禁止空泛结论，结论必须有数据或来源支撑
4. 分类按产品结构，不按营销词
5. 配件不能当整机
6. 功能词不能当主分类
7. 图片/标题/参数冲突时标记待核实
8. 所有关键数字必须标来源
9. 任务结束必须Commander复查
10. 发现新错误或新规则，只写入PENDING（待审核区），禁止直接写入正式规则库

## INDEX读取触发条件（6种）

1. 用户明确说"调用知识库"
2. 当前任务属于重复类目
3. Hermes不确定分类规则
4. Hermes曾在该类目犯过错
5. 任务涉及字段库/分类库/Prompt模板
6. Commander判断需要历史规则

## 禁止

- 每次读取整个知识库
- 每次读取所有SYSTEM_RULES
- 每次读取所有正式规则库
- 每次读取所有CASES
- 每次重写INDEX

## 适用场景

所有任务启动时的知识库读取策略。
