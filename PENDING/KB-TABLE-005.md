# 辅助列必加——中文标题100条完整翻译+竞对列

## 规则结论

Excel表格必须包含以下辅助列，不能省略：
1. 中文标题——100条完整翻译，按固定结构（品牌+型号+功能+核心参数）而非拼凑
2. 竞对标识——用户指定的竞对行用红色底色+加粗突出
3. 验证来源——标注Amazon/Alexa/卖家精灵来源
4. 辅助公式列——有效价/Coupon换算/RMB换算等

## 中文标题规则

- 结构：品牌中文名 + 型号/系列 + 核心功能 + 关键参数
- 不能只是把英文标题机翻一遍
- 不能拼凑不完整
- 格式示例："EGO 56V无刷吹叶机 650CFM 110MPH 2.5Ah"

## 竞对标识规则

- 用户指定的竞对ASIN → 红色底色(#FFC7CE) + 加粗
- 如挂烫机竞对B0FYFFPJNS、Bike Pumps竞对DSUY/ETENWOLF
- 竞对行必须占表格中最醒目的位置

## 验证来源列

- Amazon详情页验证过的行 → 绿色底色+ "Amazon+Alexa✅"
- 卖家精灵数据 → "卖家精灵"
- 可据此区分数据可靠度

## 错误表现

1. 中文标题机翻凑数
2. 缺竞对标识列
3. 竞对没有单独高亮
4. 缺验证来源列

## 正确做法

- ✅ 中文标题列：品牌+功能+参数完整翻译
- ✅ 竞对列：Y/N 或 红色高亮
- ✅ 验证来源列：Amazon+Alexa✅ / 卖家精灵
- ✅ 辅助公式列：有效价 = IF(Coupon含"%", 价格*(1-百分比), 价格-Coupon金额)

## 适用场景

所有Amazon调研Excel表格。
