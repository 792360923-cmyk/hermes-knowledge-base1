# 任务末尾自动输出知识库增量建议

## 规则结论

每次任务完成后，Hermes必须自动在末尾输出以下格式的知识库增量建议。

## 输出格式

```
【知识库增量建议】
- 本次是否需要写入知识库：是/否
- 建议写入类型：错误规则 / 字段规则 / 分类规则 / Prompt模板 / 不需要
- 建议状态：pending（待审核）
- 原因：...
- 是否需要用户审核：是
```

## 不需要沉淀时

```
本次无高价值可复用知识，不写入知识库。
```

## 优先沉淀（10类）

1. 用户纠正过的错误
2. 分类误判
3. 字段偷懒
4. 数据无来源
5. 单位混乱
6. 结论空泛
7. 公式错误
8. 表格格式错误
9. 平台规则错误
10. 角色流程错误

## 不沉淀

1. 一次性任务内容
2. 临时聊天内容
3. 无复用价值的结论
4. 没有来源的数据
5. AI自己猜的东西

## 适用场景

所有任务末尾。

## 禁止再犯

是。
