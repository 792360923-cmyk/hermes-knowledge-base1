# 交付前自查——不能把草稿当最终稿

## 规则结论

最终交付前必须自检。禁止把草稿当最终稿、把未核验内容放进最终交付、隐藏不确定项、遗漏用户明确要求。

## 交付前自查清单

- [ ] 表格是否整洁（字段名统一、表头清晰）
- [ ] 数字格式是否统一
- [ ] 空值是否标注
- [ ] 异常值是否标注
- [ ] 公式是否可追溯
- [ ] 图表是否有标题和单位
- [ ] 图片是否清晰能证明数据
- [ ] 结论是否能指导行动
- [ ] 建议是否具体
- [ ] 风险是否明确
- [ ] 是否中文优先
- [ ] 是否含主图+中文标题+分类底色
- [ ] 是否.zip打包发送
- [ ] 是否有9项复查结果
- [ ] 是否有数据来源说明
- [ ] 是否有做/不做决策

## 禁止项

1. 把草稿当最终稿
2. 未核验内容进交付
3. 隐藏不确定项
4. 删除异常值不说明
5. 改动用户原始数据不标注
6. 遗漏用户明确格式要求
7. 交付前不自检

## 适用场景

所有交付任务。

## 禁止再犯

是。
