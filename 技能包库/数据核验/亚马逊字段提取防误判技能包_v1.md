# Amazon 字段提取防误匹配 + 防编造铁律

## 最高铁律：禁止瞎猜 / 禁止套用

1. **禁止瞎猜**：任何字段没有来源就填「未标注」，禁止用推理、经验、行业常识补数据。用户原话「禁止瞎猜」。
2. **禁止套用同类产品**：同品牌同标题的不同ASIN（如同一产品的多个listing）也必须单独进页面/Alexa核验，禁止直接复制另一个ASIN的结论。
3. **全字段填满**：BSR前N的每个产品（不只竞品）都要穷举填充外观/功能/材质/颜色/容量/认证/差异化字段。非竞品禁止留空或只填竞品。
4. **「未标注」≠「不适用」**：非该功能类产品填「不适用」（确实没有）；有该功能但页面没写才填「未标注」。禁止把该填的字段留空。
5. **中英文标题双列**：英文标题列保留Amazon原文，中文标题列完整翻译。两列都必填，用户明确要求。

## 关键词提取防误匹配（正则词边界）

英文关键词做 `in` 子串匹配会大量误判，必须用词边界或完整短语：

| 目标 | 错误写法 | 正确写法 |
|------|---------|---------|
| LED灯 | `'led' in text`（误匹配 tangled/installed） | `re.search(r'\bled\b', text)` |
| 灯 | `'light' in text`（误匹配 lightweight/light weight） | `\blight\b` 且排除 lightweight |
| 认证CE | `'ce ' in text`（误匹配 piece/once/price） | 只用完整认证短语，见下 |

**LED/light 陷阱实例**：五点里 "lightweight design"（轻量）、"tangled cords"（缠结）都不是LED灯。判断「是否带LED灯」只用：`\bled\b`、`built-in light`、`illuminat`、`with light`、`light pen`。`\blight\b` 必须同时排除 lightweight/light weight。

## 认证提取（钻石画/手工类目）

禁止宽松匹配 CE/FCC（会误匹配普通单词）。聚焦完整短语：
- non-toxic / non toxic → 无毒
- child-safe / child safe → 儿童安全
- food grade → 食品级
- bpa-free / bpa free → BPA-free
- grs-certified / grs certified → GRS环保认证
- eco-friendly / eco friendly → 环保
- recycl → 可回收
- astm / cpsia → ASTM / CPSIA

## 容量/规格三源提取

容量不能只查标题，要查三个来源：
1. **SKU列**：`Size: 125ml x 1` → 125ML；`10 Piece Tray Set` → 10件
2. **标题**：`200ML`、`800mAh`、`15x10cm`
3. **详细参数 Model Name / Size 字段**：`GL-1-80mL` → 80ML

去重保持顺序，单位统一（ml/L/mAh/cm）。

## 卖家精灵 xlsx 读取

openpyxl 直接 load 会报 `ValueError: Unable to read workbook`（XML drawings 无效 editAs）。用 xlsx2csv：
```bash
xlsx2csv input.xlsx /tmp/output.csv
```
然后 csv.DictReader 读。「详细参数」列是 `Key: value | Key: value` 格式，`split(' | ')` 逐项解析，每个Key都是候选列，不能只解析两三个。

## 真空吸附 vs 机械点珠（钻石画笔类目）

吸钻笔必须区分两种机制：
- **vacuum suction 真空吸附**：可吸多种尺寸钻石，多为高端款
- **mechanical dispenser 机械点珠**：仅适配2.8mm圆钻，差评多（"doesn't work/breaks"）

主流真空吸钻笔大多**不标注最大直径mm**（行业普遍现象），不能因此套用别的产品数据，必须逐ASIN问Alexa，答不出填「未标注」。
