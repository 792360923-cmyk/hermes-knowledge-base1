# Amazon 产品数据提取避坑（通用）

从 Amazon listing / 卖家精灵导出中提取结构化字段（材质/颜色/容量/认证/充电方式/主图）时的可复用避坑规则。这些坑不依赖具体类目，做任何产品调研表都会遇到。

## 1. 卖家精灵 .xlsx 读取

卖家精灵导出的 `.xlsx` 用 openpyxl `load_workbook` 会抛 `ValueError: Unable to read workbook`（内部 drawing XML 的 `editAs` 属性非法）。**必须转 CSV 再读**：

```bash
pip install xlsx2csv
xlsx2csv input.xlsx /tmp/output.csv
```
然后用 `csv.DictReader` 读。CSV 的「详细参数」列是 `Key: value | Key: value` 格式，`split(' | ')` 解析成 dict。

## 2. 关键词子串防误匹配（高频坑：认证词 + 功能词）

认证词（CE / FCC / RoHS）**禁止用宽松子串匹配**——`'ce '` 会误匹配 piece/once/price，整列认证被污染成「CE」假数据。

**功能词同样会误命中**，裸 `in` 判断是重灾区：
- `'led' in text` 误命中 `tangled` / `installed` / `settled` → 用 `re.search(r'\bled\b', text)`
- `'light' in text` 误命中 `lightweight` / `light weight`（轻量，不是灯）→ 先排除 lightweight/light weight，或 `\blight\b` 且确认上下文不是"轻量"含义
- 判断"是否带 LED 灯"这种二值字段时，误判会把整列污染（ARTDOT 真空笔五点写 "No More Tangled Cords" 被误判成有 LED）

正确做法：
- 认证词用**词边界** `\b` 或**完整短语**匹配：`('non-toxic','无毒')`, `('child-safe','儿童安全')`, `('food grade','食品级')`, `('bpa-free','BPA-free')`, `('grs-certified','GRS环保认证')`。
- 只有 listing 标题/五点/参数**明确写**的认证才填，别从「CE 标识在图片里」这类间接信息推断。
- 找不到就填「未标注」或留空，禁止编造认证。

## 3. 容量/规格多源提取（不能只 grep 标题）

容量/数量/尺寸信息散落在**至少 4 个来源**，只查标题会漏一大半：
1. **SKU 列**：卖家精灵 SKU 常是 `Size: 125ml x 1` / `10 Piece Tray Set` / `200ML`——最常被忽略的金矿。
2. **标题**：`200ML with Silicone Brush`、`800mAh`、`A3`。
3. **详细参数 Size 字段**：`Size: 939` / `Size: 2.8mm`。
4. **详细参数 Model Name**：`GL-1-80mL`（型号里常带容量）。

按此顺序逐源尝试，去重后拼接。数值+单位一起保留（`125ML`、`800mAh`、`10件`），单位统一（ml/L/mAh/件/格/页）。

## 4. 主图下载多后缀重试

`images-na.ssl-images-amazon.com/images/I/{ID}_AC_US600_.jpg` 里 ID 含 `+` 号时直接请求会失败或返 11B 空图。可靠做法：
1. 提取 `images/I/([^._]+)` 去掉 `+` 号。
2. 依次尝试多个后缀回退（逐个请求，>1000 bytes 才算成功）：`._AC_UL320_.jpg` → `._AC_UL480_.jpg` → `.jpg`。
3. 换域名重试：`https://m.media-amazon.com/images/I/{ID}{suffix}`（比 images-na.ssl 更稳）。
4. 并发下载 `ThreadPoolExecutor(max_workers=8~12)`，失败队列单独重试。

## 5. 对比表全量填充（非仅竞品）

做竞品对比表时最常见的偷懒：只给竞品行填细分字段，其余产品留空。**所有行都要填**：
- 类型专属字段（充电/电池/续航/接口等）按产品类型批量提取；非该类型的产品填「不适用」，不是「未标注」。
- 高频卖点做成布尔列（✅/空）逐行打勾，形成可统计的渗透率矩阵，用「功能渗透率排名」支撑结论（如「LED灯45% | 耐用40%」）。
