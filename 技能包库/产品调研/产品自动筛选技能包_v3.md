## 价格带 V4（动态间距）

**核心**：间距 = max($10, 类目价格跨度 × 10%)。开区间档上限 = 底价 × 1.1。

```
算法：
1. 类目价格跨度 = 最高价格档上限 - 最低价格档下限
2. 开区间(如"105以上")→ 上限 = 105 × 1.1 = 116(非1.5)
3. 间距 = max(10, 跨度 × 0.10)
4. BSR前100找低/中/高三群，中点差≥间距，每群≥20%
5. 满足→健康 | 不满足→淘汰(附最优分组数据)
```

## 淘汰原因格式（必须含具体数据）

```
卖家垄断: "卖家集中度过高: 前三卖家占BSR前100总销量的84%(XXX等)，超过80%红线(卖家垄断)"
品牌垄断: "品牌集中度过高: 前三品牌占BSR前100总销量的81%(XXX等)，超过80%红线(品牌垄断)"
头部集中: "头部集中度过高: 前15个ASIN占类目BSR前100总销量的91%，超过80%红线(头部垄断)"
品牌缺少: "类目品牌数量少(BSR前100仅N个品牌)，品牌集中度极高或数据缺失"
液体粉末: "产品形态为粉末类(Item Form=Powder)，按筛选规则纯粉末产品不做"
价格带: "价格带未达三群标准: BSR前100跨度$N(间距需≥$M)，无法形成独立三群。最优分组: 低~$N(N%)|中~$N(N%)|高~$N(N%)，中点差$N/$N(需≥$M)"
```

## 关键教训

- Excel直读ItemForm/标题/链接，不为每个产品调asin_detail
- 类目数据永久缓存：同nodeIdPath共享全部类目指标
- 间距不能一刀切→动态间距=max(10, 跨度×10%)
- 开区间价格档上限×1.1非×1.5（避免虚高跨度卡死分组）
- 淘汰原因必须包含具体数字和最优分组数据，方便人工判断
- 挂烫机案例：低~$22(36%)/中~$38(23%)/高~$110(40%)，中点差$15/$73
