# 第一页关键词分析技能包_v2

## 格式规范

| 元素 | 设置 |
|------|------|
| 标题 | Arial 14pt Bold #1F4E79 |
| 表头 | 白字深蓝底(#1F4E79) |
| 转化率 | 百分比格式 |

## 板块颜色

🔵浅蓝(#D5E4F7)=数据 / 📗浅绿(#E2EFDA)=策略 / 🟡浅黄(#FFF2CC)=结论 / 🔴浅红(#FCE4D6)=主推词

## 4大板块

1. 关键词对比数据（≥5词，优先级/月搜索量/ABA排名/PPC竞价/购买率/需供比/推荐度）
2. 核心对比分析（月搜索/需供比/PPC/购买率4维）
3. 切入策略（冷启动→突破→放量三阶段）
4. 结论（每条≥3行：数据+分析+操作+预期）
