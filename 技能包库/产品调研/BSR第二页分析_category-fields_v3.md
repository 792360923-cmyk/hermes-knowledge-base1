## Q. 香薰机/扩香机/Diffuser（28列参考实现）

### 通用标识列
序号、主图、标题(英文)、标题翻译(中文)、链接、ASIN、品牌

### 分类列
**产品类型**（三维拼接）：
- 形态：无水冷雾 / 超声波 / 加热式
- 供电：插电 / 电池 / 电池+USB-C / 车充
- 场景：大空间(≥1000sqft) / 中空间(600-1000) / 小空间(<600) / 车载 / HVAC
- 格式：`无水冷雾·插电大空间` / `无水便携·电池` / `无水车用·电池`

### 基础数据列
价格($)、评分(1-5)、评论数、月销量

### 备注溯源列
- ★竞对（主要对标）
- Alexa已核对：XX功能
- 未标注(XX)
- 明确无(XX)
- 列表级未采集详情
- 数据源：XX

### 外观列
颜色（具体色名：Black/White/Pearl White/…）
材质（细分：Aluminum铝/PP塑料/铝+亚克力面板/…）

### 空间/容量列
覆盖面积(sq.ft)、容量(mL)

### 功能列（香薰机专属）
雾量档位（3档/可调/未标注）
静音dB（<38 dB/30-35 dB/超静音(未标dB)/未标注）
夜灯/氛围灯（有/无/未标注）
  - 灯光颜色数（3色/7色/单色暖光/…）
  - 灯效模式（白/黄/呼吸/…）
  - 亮度调节（有(遥控/APP/触控)/无(固定亮度)/未标注）

### 控制/连接列
连接方式（蓝牙APP+遥控+触控/遥控+面板/仅遥控/仅APP/…）
供电方式（插电/电池48h(USB-C)/DC-12V/…）

### 辅助功能列
定时功能（每周定时+5自定义/1/4/8h+连续/3档定时+APP排程/…）
雾化芯（2个雾化芯/未标注）
精油瓶（含X款精油/不含精油/…）
遥控器（有/无）

### 认证列
FCC（已标注/未标注）、CE

## 分层采集规则（新增）

```
第1层 竞对深度(前3个): 全部字段逐一核实，备注注明来源

第3层 列表级(第13+): ASIN/品牌/价格/类型/评分/备注="列表级未采集详情"
```
