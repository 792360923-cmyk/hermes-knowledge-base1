# 产品自动筛选技能包_v2

> 每批30个，逐批确认。规则持续优化，最终版可重复利用。

## 优化架构（最小API调用）

```
旧: 每产品9调用 × 2002 = 18000次 → 每日配额不够
新: Excel直读(0) + node映射缓存(0) + 类目缓存(0) + 仅2产品调用 × 通过数 ≈ 300-800次/全量
```

| 环节 | V1/2调用 | V3调用 | 说明 |
|---|---|---|---|
| nodeIdPath | 1/产品 | **0**（node_map.json缓存） | 每个小类目首次调asin_detail→永久缓存 |
| Item Form | 1/产品 | **0** | Excel"详细参数"列直读 |
| 标题/销量/价格 | 1/产品 | **0** | Excel各列直读 |
| 类目粗筛 | 1/类目 | 1/类目（首次）→ **0**（缓存） | cat_cache_v3.json |
| 类目深挖 | 4/类目 | 4/类目（首次）→ **0**（缓存） | 同上 |
| 产品季节性+PPC | 2/产品 | 2/通过产品 | 仅对通过类目的产品调用 |

|---|------|--------|---------|

## 价格带 V4（动态间距）

**核心**：间距 = max($10, 类目价格跨度 × 10%)

```
算法：
1. 类目价格跨度 = 最高价格档上限 - 最低价格档下限
2. 间距 = max(10, 跨度 × 0.10)
3. BSR前100中找低/中/高三群，中点差≥间距，每群≥20%
4. 满足→健康 | 不满足→淘汰

示例：
  Nail Art $0-25 → 跨度25 → 间距=max(10, 2.5)=$10
  吹叶机 $20-250 → 跨度230 → 间距=max(10, 23)=$23
  HEPA $0-400 → 跨度400 → 间距=max(10, 40)=$40
```

## 调用预算

| 阶段 | 调用次数 |
|---|---|
| node映射(全量955小类目) | ~955次（一次性） |
| 类目指标(全量) | ~955×5=4775次（缓存后永久复用） |
| 产品级(全量) | 仅通过产品×2 → 估计300-800次 |
| **全量2002产品** | **~6000次（含一次性建缓存）** |
| **日常增量(30产品/批)** | **~20-50次/批** |

## 关键教训

- 不要为每个产品调 asin_detail → Excel 直读标题/ItemForm/链接
- 类目数据永久缓存：同一个 nodeIdPath 的产品共享全部类目指标
- 间距不能一刀切 $20 → 小类目价格跨度小($0-30)只需$10间距
- 重构时对照10维度全量检查，防漏维度
- API限速 40次/分 → 深挖调用间隔≥0.4s，主循环≥0.6s
- Excel"详细参数"列 Item Form 覆盖18%，标题兜底判断
