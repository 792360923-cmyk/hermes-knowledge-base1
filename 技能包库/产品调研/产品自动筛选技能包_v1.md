# 产品自动筛选技能包_v1

## 流程

```
2002产品 → 识别小类目 → 同node合并(缓存复用)
├── 类目级粗筛(1调用): market_research_statistics → 品牌数/卖家数/新品
├── 类目级深挖(4调用): 卖家+品牌+产品集中度+价格分布 → 缓存
└── 产品级(2调用): asin_sales_trend + traffic_keyword → 季节性+PPC+品牌词
```

## 10维度判定规则

| # | 维度 | 数据源 | PASS红线 |
|---|------|--------|---------|
| 0 | 纯液体/粉末 | asin_detail overviews | ItemForm=液体/粉末/颗粒→不做 |
| 1 | 卖家结构 | market_seller_concentration | Top3销量>80% |
| 2 | 专利 | 智慧芽(暂缓) | 发明专利→不做 |
| 3 | 季节性 | asin_sales_trend | 近8月≤4月有销(>200单) |
| 4 | 关键词 | traffic_keyword | 核心词PPC>$4 / 品牌词≥70% |
| 5 | 品牌/自营 | market_brand_concentration | Top3>80% |
| 6 | 头部集中 | market_product_concentration | 前15ASIN>80% |
| 7 | 售后 | 用户自看 | 不判定 |
| 8 | 同质化 | 用户人工 | 不判定 |
| 9 | 新品机会 | statistics | 新品>5%加分 |
| 10 | 价格带 | price_distribution | 间距法(见下) |

## 价格带 V3（间距法）

BSR前100中找低/中/高三群，相邻群价格中心点间距≥$20，每群销量≥20%。

```
算法：
1. 按价格档中心点排序
2. 枚举分割点(i,j)，群1=0:i, 群2=i:j, 群3=j:n
3. 三群中心点间距≥$20 且 每群占比≥20% → 通过
4. 不满足→淘汰
```

## 液体/粉末判定

- 固体→做: gummy/softgel/capsule/tablet/chews/bar
- 液体→不做: drop/liquid/oil/spray/serum/香水/乳液/凝胶
- 粉末→不做: powder/granule/颗粒/creatine/protein/whey

## 调用优化

- 类目级缓存：同小类目产品共享
- 两级筛选：粗筛先淘汰→深挖→产品级
- 速率控制：主循环0.7s + 深挖0.4s + 重试机制

## 输出格式

序号/产品链接/ASIN/品牌/中文标题/小类目/产品形态/月销量/价格/判定/淘汰原因/加分项

🟢通过(绿底) 🔴PASS(红底) ⚠️待核实(黄底)
