# BSR单页分析技能包_v3

> 一页Excel完成BSR TOP100全量分析。相比v2.1的「多Sheet」结构，v3升级为「单Sheet + 底部结论区」。
> 输入：卖家精灵导出的BSR前100 Excel + 目标ASIN + 类目链接。
> 输出：单Sheet Excel，含表头冻结筛选、中文标题、类目专属细分字段、竞品颜色标记、底部结论区（市场结构/演变/竞品对标/切入建议/兼容性Q&A）。

## 核心升级（v2.1 → v3）

| 维度 | v2.1 | v3 |
|------|------|-----|
| Sheet结构 | 多Sheet | 单Sheet一页到底 |
| 表头 | 无冻结筛选 | 冻结A4 + 全表自动筛选 |
| 颜色 | 功能分色(红蓝绿黑) | 只标竞品(红=目标/蓝=竞品/白=无关) |
| 中文标题 | 品牌+材质+功能+规格 | [设备/类型] 品牌 材质+外观 特征 |
| 卖点 | 不翻译 | 中文短词逗号分隔翻译 |
| 分类 | 字段库候选 | 类目专属穷举细分 |
| 结论 | 表格内 | 底部5模块结论区 |
| 兼容性 | 无 | 跨代/跨机型Q&A核实 |

## 前置条件

1. 卖家精灵导出 `BSR{类目名}Current-100-US-{日期}.xlsx`
2. 目标 ASIN + 类目链接
3. 当天汇率：`curl -s "https://api.exchangerate-api.com/v4/latest/USD" | python3 -c "import sys,json; d=json.load(sys.stdin); print(f'{d[\"rates\"][\"CNY\"]:.2f}')"`

## 7步执行流程

### Step 1: 数据加载 + 目标确认
- Pandas `read_excel(engine='openpyxl')` 读BSR前100
- `asin_detail` 拉目标ASIN详情（品牌/类目/BSR/上架/变体/参数）
- 确定竞品范围 = 同设备/同材质/同适配（才标色，无关白底）

### Step 2: 类目定制分类维度（核心）
不同类目 → 不同细分列。从标题+卖点+参数穷举所有维度。

**通用列（始终保留）**：
`#`,`图`,`中文标题`,`品牌`,`适配设备/大类`,`材质细分`,`外观类型`,`扣环/连接方式`,`价格$`,`Prime$`,`Coupon`,`评分`,`评数`,`上架`,`ASIN`,`链接`,`月销`,`月销$`,`月销¥`,`包装数`,`佩戴/安装方式`,`防水/防护`,`宽度/规格`,`品牌类型`,`AC`,`BSeller`,`变体`,`天数`,`LQS`,`FBA`,`运费$`,`A+`,`视频`,`卖点(中文)`

**类目专属列**：
- 表带类：适配设备, 材质细分(16种), 外观类型(10种), 扣环(7种), 佩戴位置, 防水
- 烟熏器类：材质, 充电方式, LED灯, 显示屏, 安全盖, 风扇, 木屑数, 冷烟, 含喷枪, 过滤嘴
- 调酒器类：件数, 材质, 颜色, 支架类型, 摇酒器类型, 捣棒, 量杯, 过滤器, 配方卡

### Step 3: 中文标题
格式 `[设备/类型] 品牌 材质+外观 特征`
- 表带：`[Whoop5.0] omee 硅胶蕾丝镂空 2件装`
- 烟熏器：`[电动] smokpub USB充电 6木屑 磁吸盖`

### Step 4: 中文卖点翻译
英文卖点→中文短词逗号分隔。映射表见 template.py：
soft→柔软, breathable→透气, stretchy→弹力, waterproof→防水, sweatproof→防汗, washable→可水洗, quick-dry→速干, easy install→易安装, magnetic→磁吸, lace→蕾丝镂空, floral→花纹雕刻, multi-pack→多件装

### Step 5: 颜色标记
- 🔴 红底 #FFC7CE = 目标ASIN
- 🔵 蓝底 #BDD7EE = 高相关竞品（同设备/同适配）
- ⬜ 白底 = 不相关产品 → 不标任何颜色

### Step 6: Excel格式化
- R1标题：合并整行 13pt Bold #1F4E79 浅灰底
- R2概览：合并整行 9pt Bold（100产品月度统计）
- R3表头：8pt Bold 黑字 浅黄底 #FFFFCC 居中换行
- 表头冻结 A4，自动筛选 A3:XX103
- 图片55×55嵌入，行高55px
- 列宽按 template.py wmap 字典

### Step 7: 底部结论区（5模块）
1. **市场结构**：材质/适配/外观/扣环/品牌各轴分布 + 统计
2. **市场演变**：上架年份分组 + 功能渗透率时间轴 + 明年预判
3. **竞品对标**：目标赛道6-8个TOP竞品逐一分析
4. **切入建议**：3方向 + 定价 + 配置 + 理由 + 不做清单
5. **兼容性Q&A**：跨代/跨机型核实（如适用）

结论格式：模块标题11pt Bold #1F4E79 | 🥇绿底 #E2EFDA | ❌红底 #F2DCDB | ✅最终决策11pt Bold绿字#006100绿底

## 兼容性核实方法（表带类必做）

目标产品适配某机型时，必须核实跨代/跨机型兼容性：
1. 逐条扫描竞品 Product Bullets 里是否标注「Not compatible with XXX」
2. 统计明确标注的品牌数量
3. 跨机型适配：扫描全部100个标题+五点，确认是否有产品同时适配两种机型
4. 结论写入底部Q&A区

案例（替换表带）：Whoop 5.0表带11/15个明确标注不兼容4.0；0/100产品同时适配Whoop+Fitbit（物理接口不同）。
