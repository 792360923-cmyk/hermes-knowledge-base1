## §1 三维产品分类系统（形态 × 外观 × 功能）

> ⛔ **铁律**：任何BSR第二页分析，必须先建立三维分类维度表。禁止只用一个大类概括。

### 1.1 三维定义

| 维度 | 定义 | 来源 | 强制要求 |
|------|------|------|---------|
| **形态** | 产品物理形态/使用方式/供电类型 | 标题+图片+Product Overview | 必须≥2级分类 |
| **外观** | 材质/颜色/尺寸/造型/表面工艺 | 图片+参数+五点 | 材质必须到具体材质名（禁止"金属"→必须"铝/不锈钢/铁"） |
| **功能** | 核心功能+辅助功能+控制方式 | 五点+视频+A++Alexa | 每个功能必须验证是否真实存在 |

### 1.2 分类表示例（无水香薰机）

```
形态维度：
  一级：无水冷雾 / 超声波（淘汰，不纳入无水竞品）
  二级：插电大空间 / 便携电池 / 车用电池 / HVAC壁挂
  三级：大空间(≥1000sqft) / 中空间(600-1000) / 小空间(<600)

外观维度：
  材质：铝 / PP塑料 / 铝+亚克力 / 未标注
  造型：塔式 / 圆柱 / 迷你 / 桌面 / 壁挂
  颜色：Black / White / Pearl White / …

功能维度：
  控制：APP+遥控+触控 / 仅遥控 / 仅APP / 仅触控
  灯光：RGB多色+亮度调节 / 单色夜灯 / 无灯光
  静音：标dB值 / 超静音(未标dB) / 未提静音
  定时：多档+自定义 / 固定档位 / 无定时
  覆盖：≥2000sqft / 1000-2000 / <1000
```

### 1.3 分类维度发现流程

```
Step A: 扫前20个ASIN的标题+主图 → 提取所有产品形态词 → 归类
Step B: 扫前20个ASIN的五点+图片 → 提取所有材质/外观特征 → 归类
Step C: 扫前10个竞对的A+/视频 → 提取所有功能卖点 → 归类
Step D: 输出三维分类维度表 → 用户确认 → 开始逐ASIN标注
```

### 1.4 产品类型列格式

> ⛔ 产品类型列必须是 **形态·功能·空间** 三维拼接，禁止写一个笼统词。

格式：`[核心形态]·[供电/使用方式]·[场景/空间]`
示例：
- `无水冷雾·插电大空间` ✅
- `无水便携·电池` ✅
- `无水车用·电池` ✅
- `无水冷雾·插电大空间(HVAC)` ✅
- `Waterless Diffuser` ❌ 太笼统

## §2 类目专属字段自动发现流程

> ⛔ 不同类目有不同的核心字段。禁止写死字段表，必须从实际竞品中提取。

### 2.1 四步发现法

```
Step 1 — 竞品标题扫描：扫前20ASIN标题，提取所有功能词/参数词
    → 例：香薰机出现"1000 sqft/120mL/3档/蓝牙APP/遥控/冷雾/夜灯/定时"
    → 每个词=一个候选列

Step 2 — 竞品五点/参数表扫描：扫前10竞对的Product Overview+五点
    → 例：香薰机出现"雾化芯/FCC认证/静音dB/亮度调节/灯效模式/精油瓶"
    → 每个参数=一个候选列

Step 3 — 竞品A+/视频扫描：看前5竞对的A+和视频
    → 找出文字未提但图片展示的功能
    → 例：视频展示了APP界面→确认APP控制列

Step 4 — Alexa逐ASIN核验：对前12个主要竞对，逐一用Alexa问核心功能
    → 例："Does this diffuser have a night light?" "Can I adjust brightness?"
    → 结果填入备注列：「Alexa已核对：XX」
```

### 2.2 字段表输出格式

| 字段 | 来源 | 采集难度 | 是否纳入 |
|------|------|---------|---------|
| 雾量档位 | 标题/五点 | 低 | ✅ |
| 静音dB | 五点/参数 | 中（仅Maromalife标注） | ✅ |
| 灯效模式 | A+/产品页 | 高（需逐ASIN确认） | ✅ |
| FCC | 产品页参数 | 中 | ✅ |

### 2.3 字段穷举不设上限

> ⛔ 宁多勿省。香薰机案例=28列。其他类目按实际需要，不设上限。

## §3 备注溯源标记规范

### 3.1 标准标记格式

| 标记类型 | 格式 | 含义 |
|---------|------|------|
| 竞对标记 | `★竞对` | 作为对标的主要竞品 |
| Alexa核实 | `Alexa已核对：XX功能有/无` | 通过Alexa确认过的信息 |
| 未标注 | `未标注(XX)` | 页面未提但预期应有的参数 |
| 明确无 | `明确无(XX)` | 页面/图片明确显示没有 |
| 列表级 | `列表级未采集详情` | 降级采集的行 |
| 数据源 | `数据源：XX` | 标注数据来源 |

### 3.2 使用规则

```
1. 主要竞对（前12个）：所有字段必须逐一核实，备注列写清来源
2. 列表级（第13个之后）：只采集标题/ASIN/价格/品牌/评分等基础字段，备注写"列表级未采集详情"
3. 竞对标记：只标2-3个最相关的直接竞品
4. Alexa核对：凡是有疑问的功能（灯/蓝牙版本/APP名称/亮度调节等），必须用Alexa逐ASIN问
```

## §4 分层采集策略

### 4.1 三层分级

| 层级 | 范围 | 采集深度 | 字段数 |
|------|------|---------|--------|
| **第1层 — 竞对深度** | 前2-3个对标竞品 | 全字段（28列+），逐一核实 | 全部 |
| **第2层 — 类目详情** | 第4-12个主要产品 | 全字段，Alexa核验核心功能 | 全部 |
| **第3层 — 列表级** | 第13个之后 | 基础字段（ASIN/品牌/价格/类型/评分/备注="列表级未采集详情"） | ~10列 |

### 4.2 层级切换判断

```
达到以下条件之一可切换到第3层列表级：
- 已经覆盖了该品类所有主要形态类型
- 后续产品都是重复形态且无新卖点
- 已超过15个产品且无新品牌/新功能出现
```

## §5 结论区结构化模板（7段式）

> ⛔ BSR第二页必须输出以下7段结论，缺一不可。

### 5.1 7段模板

```
【1. 市场判断】
- 类目BSR前100的主力产品类型是什么？（数量+价格带）
- 你关注的细分赛道有多少款？（数量+价格范围）
- 一句话给出"做/不做"判断 ✅/❌

【2. 对标竞对】
- 选定的对标ASIN是谁？（品牌+价格+核心卖点）
- 它处于什么市场定位？（高端/中端/低端）
- 为什么选它做对标？

【3. 关键功能判断】
- 类目判断标准是什么？（哪些功能是主流标配）
- 竞对有/无的核心功能逐项列出

【4. 差异化空档】
- 你的产品和竞品比的真正差异化在哪里？
- 哪些是"别人有但没做好"的机会？
- 哪些是"别人根本没有"的空档？
- ⚠️ 防止误判空档：必须逐个竞对核实再做结论

【5. 建议方向】
- 做什么形态？（三维分类定位）
- 选什么配置？（核心参数值）
- 加什么功能？（差异化卖点）

【6. 定价建议】
- 对标价格区间
- 建议定价+理由

【7. 风险提示】
- 认证/专利/差评集中点
- 需要注意的坑
```

### 5.2 参考案例：无水香薰机结论

```
【结论·做/不做】建议做 ✅

1) 市场判断：类目BSR前80超声波加水款占主流(~50款 $10-25)；无水冷雾是细分(~21款 $28.99-$169.99)。

2) 对标竞对：Fajuod $89.98(铝壳/APP+遥控+触控/3档/120mL/2雾化芯) 处于无水大空间款中高端。

3) 灯光/夜灯是类目判断标准：超声波主流几乎标配7色灯；无水12款里6款带灯(已用Alexa逐一核对)。

4) 亮度调节：竞对Fajuod有(遥控/APP/触控+3模式)、Airversa RD1有(触控)；Maromalife/XEITIN Tower未标注；The AirScent明确无。
   所以'亮度调节'不是空档，你的差异化应是【更多亮度档位+更多灯效】超越Fajuod，而非从无到有。

5) 真正空档=【更静音】：竞对只写'ultra-quiet'未标dB，你做标出dB数值(如<30dB)是实打实差异。

6) 建议方向：无水冷雾插电大空间款，铝壳，1000-1100sqft，120mL，APP+遥控+触控，加夜灯+多档亮度调节+更多档位+更静音(dB可标)，定价对标$80-90。
```

## §6 BSR第二页固定要求（V3增强版）

### 6.1 Excel格式

- ✅ 单页Sheet（非多Sheet）
- ✅ 表头冻结+所有列筛选
- ✅ 竞品标色：目标品红底、直接竞品蓝底、无关品不标色
- ✅ 中文标题翻译列独立存在
- ✅ 固定列顺序：序号→主图→标题→标题翻译→链接→ASIN→品牌→产品类型→价格→…

### 6.2 竞品时效

- 主要对标竞品必须**近一年内上架**（往前推12个月）
- 超一年的只做参考，最多放1-2个做价格/品牌参考

### 6.3 功能分析深度（禁止笼统词）

功能分析禁止只写"电池/电机/防水/续航"，必须逐个拆解到具体数值：
- 电机：有刷还是无刷？转速多少 RPM？
- 电池：容量多少 mAh？单块还是双块？
- 防水：具体 IP 等级（IP65/IP67/IPX4/无）
- 续航：具体分钟数
- 充电：Type-C/Micro USB/磁吸充电/专用充电座/插电
- 电压/功率：具体 V / W

### 6.4 分类清晰度

- 电动/手动/机械逐ASIN核实，automatic≠电动
- 无电源证据（电机/电池/充电接口三个证据一个都没有）禁止归电动
- 功能词不能当主分类，按物理形态分类
