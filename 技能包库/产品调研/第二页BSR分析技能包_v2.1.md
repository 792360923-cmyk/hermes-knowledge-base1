# 第二页BSR分析技能包_v2.1

> SYS-008 §七（全参数字段库）+ §十五（宁多勿省）+ §十六（防偷懒工程）驱动。

## 全参数字段库（SYS-008 §七 — 每次调研前强制建立）

调研新类目前按四步流程建立：14来源抽样→输出字段库→17大类检查→类目专属字段

## 4数据来源

卖家精灵/Amazon browser_navigate/Alexa购物助手/图片识别

## 固定17列

小类排名序号/图片(70×70)/中文标题/链接/品牌/大类目排名/价格/Coupon/评分/评论数/上架年份/ASIN/FBA运费/配送渠道/月销量/月销售额USD/月销售额RMB/竞品类型

## 功能着色

🔴红色=差异化核心 / 🔵蓝色=成本相关 / 🟢绿色=客户在意 / 普通=黑色

## 多层分类

功能形态(第一层)→外观造型(第二层)→使用场景(第三层)。"通用"占比<10%

## 防偷懒验证（SYS-008 §十六）

- [ ] 无笼统词(USB/电池/遥控/材质/防水→细分)
- [ ] 无空泛结论
- [ ] 所有数字有来源
- [ ] "通用"<30% / "其他"<10% / Unknown<40%
- [ ] 表格≥10列 / 结论≥3句

## 汇率

月销售额RMB用当日实时汇率，标注日期
