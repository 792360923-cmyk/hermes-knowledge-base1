# 第1页 — 关键词数据分析

## 格式规范

| 元素 | 设置 |
|------|------|
| 标题 | Arial 14pt Bold #1F4E79 |
| 板块标题 | Arial 12pt Bold #1F4E79 + 板块背景色 |
| 表头 | 白字深蓝底(#1F4E79) |
| 转化率 | 百分比格式(63.15%) |

## 板块颜色

- 🔵 浅蓝(#D5E4F7) = 数据板块
- 📗 浅绿(#E2EFDA) = 策略板块
- 🟡 浅黄(#FFF2CC) = 结论板块
- 🔴 浅红(#FCE4D6) = 主推词/风险

## 板块1: 关键词对比数据

字段: 优先级/关键词/月搜索量/ABA排名/PPC竞价/购买率(%)/点击转化率(%)/需供比/商品数/竞争度/推荐度。至少5个关键词，主推词行用红色背景。

## 板块2: 核心对比分析

维度/词1/词2/词3/词4/结论。4行: 月搜索/需供比/PPC/购买率。蓝海词红色字体。

## 板块3: 切入策略

三阶段: ①冷启动→②突破→③放量。每阶段含: 主推词/月搜索/PPC预算/打法/预期。

## 板块4: 结论（必须详细！）

每条结论**不少于3行**，必须包含：
1. **数据**：具体月搜索量/ABA排名/PPC竞价/SPR/购买率
2. **分析**：为什么选/不选这个词（对比、差距倍数、蓝海判断）
3. **操作**：放Title/Bullet/Search Terms哪个位置、精确出价区间（PPC×1.1~1.3）
4. **预期**：占出单量百分比、ROI判断

格式：🔴首选(红底)/🔴次选(红底)/🟡辅助(黄底)/⚠️避免(黄底)。每段110行高，换行。

## 标准参考

黄油搅拌机 IFOLO B0G4VC2P5C 第1页（/tmp/page1_butter_final.xlsx）为已验证标准。详见 references/butter-churn-page1-reference.md。

## ⚠️ ABA关键词扩词铁律

在 amz123.com 做 ABA 热搜词扩词时，**禁止只用 curl 简单正则**。实测 curl 丢失大量结果（star projector: curl 5条 vs 浏览器 12条）。必须用浏览器逐页渲染后 browser_console 提取完整数据。

## 数据来源

卖家精灵导出 Excel（KeywordHistory/KeywordMining）。Amazon US站点。每字段标注来源。截图插入 Excel。禁止编造数据。

## 验证标准

- 5板块结构完整 + 颜色区分 + 百分比格式 + 明确主推词和回避词
