# 防偷懒工程技能包_v1

> SYS-008 §十六正式规则驱动。防偷懒不能只靠提醒，必须有程序化拦截。

## 核心理念

**规则在 prompt 层 = 贴在墙上的标语。验证在代码层 = 装在系统里的闸门。**

## 机制一：双轮制流程

角色执行→防偷懒验证器(自动扫描)→通过?→Commander复查→交付。不通过则自动退回+违规清单。

## 机制二：自动验证规则

### 笼统词扫描
USB笼统/电池笼统/遥控笼统/材质笼统/防水笼统 → ❌ 退回

### 空泛结论扫描
"市场不错/竞争激烈/有机会/可能/大概/估计" → ❌ 退回

### 来源扫描
有数字无来源/来源为"网络/亚马逊" → ❌ 退回

### 统计检测
"通用">30%→❌ / "其他">10%→❌ / Unknown>40%→❌

## 机制三：子代理反偷懒指令

所有 delegate_task 前置注入：禁止分类合并一列/通用>50%/USB笼统/结论空泛/不标来源/字段只采固定几个/冲突硬判

## 机制四：冲突解决

SYS-005 省Token条款全面让步。规则不设上限，全量读。

## 机制五：Commander终审拦截

表格<10列 / 结论<3句 / 无"待核实" / 来源都一样 / 大面积"通用" / 文件很小 → 退回

## 偷懒=返工+记入失败案例
