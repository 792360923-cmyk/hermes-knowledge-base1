# 知识库工作流技能包_v2

> SYS-008 §十一+§十五+§十六驱动。v1→v2升级：不设规则卡上限，全量读取，宁多勿少。

## 核心理念

规则卡是无数次返工的血泪教训。不读知识库就做任务=裸奔=返工。

## 🔴 任务开始—强制流程

### 1. 拉知识库
```bash
git clone/pull https://github.com/792360923-cmyk/hermes-knowledge-base1.git /tmp/hermes-kb
```

### 2. 读知识索引
`read_file /tmp/hermes-kb/知识索引.md`

### 3. 按任务类型定位
产品调研→来源规则+分类规则+字段规则 / 关键词→关键词规则卡 / Listing→Listing规则卡

### 4. 全量读取（宁多勿省 — SYS-008 §十五）
**不设读取上限。** 所有相关规则卡+所有失败案例全读。不再受"最多3-5条"限制。

⛔ 严禁不开知识库就做任务！

## 🟢 任务结束—强制流程

1. 输出【知识库增量建议】（PENDING-rule/fix/case/category）
2. 写入待审核区
3. git commit + push
4. 禁止直接写已验证

## 全局规则更新管线（设置/更新全局规则时走）

1. Pull最新
2. 对比新旧
3. 合并写入待审核区
4. 等用户确认
5. 升级+归档旧规则
6. 更新索引+日志
7. 同步SOUL.md
8. 更新memory
9. push
