# 防偷懒自动验证器_v1

> 路径: `~/.hermes/skills/anti-slacking-engineering/scripts/anti_slacker.py`
> 不依赖 LLM，纯 Python 正则+统计，零幻觉。

## 功能

交付前强制扫描，14条规则四大维度：

| 维度 | 规则 | 严重性 |
|------|------|--------|
| VT-USB/BATTERY/REMOTE/MATERIAL/WATERPROOF | 笼统词检测 | BLOCKER |
| HL-MARKET/COMPETE/OPPORTUNITY/VAGUE/EMPTY | 空泛结论 | BLOCKER |
| SRC-MISSING/SRC-VAGUE | 来源检测 | BLOCKER |
| STAT-GENERIC/STAT-OTHER | 统计异常 | BLOCKER |
| TBL-FEW-COLUMNS | 列数不足 | BLOCKER |
| ST-CONC-SHORT/ST-FILE-SMALL | 结构缺陷 | WARNING |

- BLOCKER → 禁止交付，必须修正
- WARNING → 提醒但不阻塞

## 使用方式

```bash
# 文本验证
python3 ~/.hermes/skills/anti-slacking-engineering/scripts/anti_slacker.py report.txt

# CSV表格验证
python3 ~/.hermes/skills/anti-slacking-engineering/scripts/anti_slacker.py --csv data.csv

# 片段验证
python3 ~/.hermes/skills/anti-slacking-engineering/scripts/anti_slacker.py --text "USB充电 市场不错"

# JSON输出(程序调用)
python3 ~/.hermes/skills/anti-slacking-engineering/scripts/anti_slacker.py --json report.txt

# 管道
echo "文本" | python3 ~/.hermes/skills/anti-slacking-engineering/scripts/anti_slacker.py -
```

退出码: `0`=通过 `1`=有BLOCKER

## 验证结果

- ✅ 合规输出 → 全部通过，可交付
- ❌ 偷懒输出 → 14个违规一网打尽（测试一把抓）
- ⚠️ WARNING不阻塞 → 短文本/少结论仅提醒

## 一句话

**规则从 prompt 层搬到了验证层。偷懒输出到不了用户眼前。**
