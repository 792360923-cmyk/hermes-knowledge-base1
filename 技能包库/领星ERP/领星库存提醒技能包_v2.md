# 领星 ERP 库存安全天数提醒表

从领星 ERP 开放 API 拉取库存+销量+货件数据，计算每款 SKU 的剩余安全天数，三档预警，国家库存独立拆分，导出 Excel 发到 Discord。

## 触发条件
- 用户要"库存提醒表""库存安全天数""领星库存导出""每周库存报表"等

## 关键口径（用户 2026-08 确认）

| 项 | 口径 |
|---|---|
| 日均销量 | 销量统计接口 type=2(销量=件数)，7/14/30天各算一个 |
| 安全天数公式 | (FBA可售 + 签收中 + 在途) ÷ 日均销量 |
| 预警判定 | 仅按 30天安全天数 < 45 天 判"需补货" |
| 三档预警 | 需补货(库存>0,30天<45) / 已断货(库存=0,30天有销量) / 库存积压(库存>0,30天零销量) |
| 国家列 | 中文国名(美国/德国/法国…)；共享库存拆到每个国家，每国一行 |
| 在途/签收中 | 用货件列表按 ship_to_address.country_code 精确拆到目的国(方案B) |
| 过滤 | ①无销量且无库存的死SKU删除 ②fnsku黑名单删除 |

## 领星 API 认证

- 域名 `https://openapi.lingxing.com`，接口文档 `https://apidoc.lingxing.com`
- 获取 token：`POST /api/auth-server/oauth/access-token`，form 参数 `appId` + `appSecret`（**必须 form-urlencoded，不是 JSON**）
- token 有效期 2 小时，需自动刷新
- 签名 sign：参数 ASCII 排序 → `key=value` 拼接(空值跳过) → MD5 大写 → AES/ECB/PKCS5(密钥=appId) → base64 → urlencode
- 公共参数 access_token/app_key/timestamp/sign 放 query，业务参数 POST 放 body(JSON)
- 限流：令牌桶，销量统计接口容量5(可5并发)
- 密钥(appId/appSecret)存于本地 /root 脚本，不入库

## 数据源接口

| 数据 | 接口 | 关键字段 |
|---|---|---|
| FBA库存 | `/basicOpen/openapi/storage/fbaWarehouseDetail` (POST) | afn_fulfillable_quantity(可售)/afn_inbound_shipped_quantity(在途)/afn_inbound_receiving_quantity(签收中)/fba_storage_quantity_list(共享分国家)/share_type(0非共享1北美2欧洲) |
| 销量 | `/erp/sc/data/sales_report/asinDailyLists` (POST) | type=2销量, event_date单日, asin_type=2(msku), 需拉30天 |
| 货件 | `/erp/sc/data/fba_report/shipmentList` (POST) | shipment_status(SHIPPED/IN_TRANSIT/DELIVERED=在途; RECEIVING/CHECK_IN=签收中)/ship_to_address.country_code(目的国)/item_list[].msku+quantity_shipped+quantity_received |
| 店铺列表 | `/erp/sc/data/seller/lists` (GET) | sid/mid/name/country |
| 市场 | `/erp/sc/data/seller/allMarketplace` (GET) | mid->code(国家二字码) |

## 脚本结构（/root/ 下）

| 脚本 | 作用 |
|---|---|
| `lx_fetch.py` | 拉数据 → 缓存 /root/lx_cache.json（店铺+货件在途拆分+库存+销量） |
| `lx_assemble.py` | 读缓存 → 组装表格 → 三档预警 + 死SKU过滤 + fnsku黑名单过滤 → /root/lx_result_v2.json |
| `lx_export_v2.py` | 读结果 → 生成 /root/inventory_reminder.xlsx（三档着色+冻结表头+筛选）+ 打包 zip |
| `lx_blacklist.json` | fnsku 黑名单（34个） |

## 执行流程

```bash
cd /root && python3 lx_fetch.py      # 拉数据(约10分钟, 89店×30天销量)
cd /root && python3 lx_assemble.py   # 组装+过滤
cd /root && python3 lx_export_v2.py  # 生成Excel+zip
```

发送：Discord 发 .xlsx（<3MB直接发）。收不到时改打包 zip 或用短文件名。

## 踩坑记录（务必遵守）

1. FBA库存 length 上限 200（不是5000），需分页
2. 销量统计接口无 15天，只有 7/14/30（用户曾口误15天=14天）
3. AsinListNew(产品表现)接口的 volume 与 asinDailyLists 销量口径不一致，**必须用销量统计接口**
4. sid=0 的欧洲共享仓聚合行：用 seller_group_name 匹配店铺归国，不能按 sid 找
5. query_fba_storage_quantity_list 必须传字符串 'true'，传布尔 True 会导致 sign 错误
6. token 过期(2h)返回 code 2001003，需自动刷新重试
7. 泛欧共享库存：FBA可售能拆国家(fba_storage_quantity_list)，在途/签收中不能拆，需用货件列表按目的国拆
8. 营销词≠分类等 SYS-008 规则不适用于本任务（本任务为库存/销量数据，非产品分类调研）
