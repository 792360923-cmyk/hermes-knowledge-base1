# 技能包库

> Hermes（AI 助手）技能包统一归档库。所有 Skill（技能包）按中文分类管理，中文命名，版本号管理，旧版不删、不覆盖。

## 一、这是什么

本目录是威猛先生（严宇坤）所有 Hermes 技能包的**统一归档仓库**。

- 每个技能包是一个 `.md` 文件（Markdown 格式，可转成 Skill 技能包给 AI 学习）
- 按中文分类目录存放
- 每次更新新增版本（v1 → v2 → v3 ...），**旧版本永远保留**
- 由「技能包索引.md」统一登记，由「更新日志.md」记录每次变更

## 三、文件命名规则

格式：`中文技能包名称_v版本号.md`

示例：
- 产品调研第二页BSR分析技能包_v1.md
- 类目专属字段发现技能包_v2.md
- 亚马逊卖家精灵交叉验证技能包_v1.md

**禁止**：skill.md / new.md / final.md / latest.md / copy.md / old.md / test.md / 未命名.md / 临时.md

## 四、版本规则

1. 第一次上传为 **v1**。
2. 每次修改新增版本（v2、v3、v4 ...），**不覆盖、不删除旧版本**。
3. 小修改也必须新建版本。
4. 版本号最大 v999，连续递增不跳号。
5. 当前推荐版本在索引里标注「当前推荐」；旧版本标「历史版本」。
6. 废弃版本标「已废弃」，但不删除文件。

## 五、状态（统一中文）

- 待审核 — 新上传但未确认
- 当前推荐 — 用户确认可用后
- 历史版本 — 被新版本替代的旧版本
- 已废弃 — 明确错误或不再适用
- 测试版 — 测试中的技能包
- 草稿 — 未完成内容
- 禁止使用 — 有风险或错误严重

## 七、安全规则（禁止写入技能包）

- API Key（接口密钥）、AppSecret（应用密钥）
- 飞书 Webhook（回调地址）、GitHub Token（访问令牌）
- ERP 账号密码、Cookie（浏览器凭证）
- 客户隐私、买家地址、订单隐私
- 未脱敏截图

需要密钥时，只能写：**请放入 VPS .env 环境变量，不要写入 GitHub（代码仓库平台）。**

## 八、调用规则

Hermes 使用技能包时：
1. 先查「技能包索引.md」
2. 优先用「当前推荐」版本
3. 不调用「已废弃」「禁止使用」版本
4. 测试版只在用户明确要求时调用
5. 调用前输出：名称 + 版本 + 文件路径 + 状态
