# Amazon Competitor Scraper v2.0.0

## Core Question

> — I need real Amazon product data. How do I get it when my VPS is blocked?

## Three Collection Modes

This skill provides 3 modes for collecting Amazon competitor data:

| Mode | Name | Best For | Requires |
|------|------|----------|----------|
| 1 | 浏览器人工辅助 | Quick one-off lookups | Playwright + user browser interaction |
| 2 | 本地浏览器接入 | Stable, high-volume scraping | User's local Chrome with Amazon login |
| 3 | 数据输入模式 | Bulk analysis from existing data | CSV/Excel/ASIN list file |

---

# Mode 1: 浏览器人工辅助模式 (Browser-Assisted)

## Flow

```
1. Open Amazon search page in headful browser
2. User completes verification (captcha/login)
3. System auto-detects page ready
4. Auto-extracts all product data
5. Saves as structured JSON
```

## Usage

```bash
# Launch interactive scraper
python3 scripts/mode1_browser_assisted.py --keyword "USB Galaxy Star Projector"

# With custom output
python3 scripts/mode1_browser_assisted.py --keyword "yoga mat" --output /tmp/yoga_results.json --max 20
```

## Behavior

- Opens a VISIBLE Chromium browser (headless=false)
- Navigates to Amazon search page
- **Waits for user to complete verification** (detects when results load)
- Auto-extracts: title, ASIN, price, rating, reviews, bullets
- Closes browser after extraction

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `--keyword` / `-k` | string | required | Search keyword |
| `--max` / `-n` | int | 20 | Max products |
| `--output` / `-o` | string | `/tmp/amazon_results.json` | Output file |

# Mode 2: 本地浏览器接入模式 (Local Browser Connect)

## Flow

```
1. User opens Chrome on local machine
2. User enables remote debugging: chrome --remote-debugging-port=9222
3. User logs into Amazon normally
4. Hermes connects via CDP (Chrome DevTools Protocol)
5. Hermes reads pages through user's real browser session
```

## Setup (User Side)

### Step 1: Close all Chrome instances

### Step 2: Launch Chrome with remote debugging

**macOS:**
```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
```

**Windows:**
```cmd
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
```

**Linux:**
```bash
google-chrome --remote-debugging-port=9222
```

### Step 3: Log into Amazon in this Chrome window

### Step 4: Tell Hermes to connect

```
"连接本地浏览器，搜索 USB Galaxy Star Projector"
```

## Usage (Hermes Side)

```bash
# Connect to local Chrome via CDP
python3 scripts/mode2_cdp_connect.py --keyword "USB Galaxy Star Projector" --cdp-port 9222

# With SSH tunnel if remote
python3 scripts/mode2_cdp_connect.py --keyword "yoga mat" --cdp-host 127.0.0.1 --cdp-port 9222

# Extract from current active tab
python3 scripts/mode2_cdp_connect.py --current-tab
```

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `--keyword` / `-k` | string | required | Search keyword |
| `--cdp-host` | string | 127.0.0.1 | CDP host |
| `--cdp-port` | int | 9222 | CDP debug port |
| `--current-tab` | flag | false | Use current tab instead of searching |
| `--max` / `-n` | int | 20 | Max products |
| `--output` / `-o` | string | `/tmp/amazon_results.json` | Output file |

## Advantages

- ✅ Uses user's real browser fingerprint
- ✅ Uses user's real Amazon cookies/login
- ✅ No captcha issues
- ✅ No VPS IP blocking
- ✅ Amazon sees a real residential user

# Mode 3: 数据输入模式 (Data Input)

## Flow

```
1. User provides file (CSV/Excel/ASIN list)
2. System parses and validates input
3. System analyzes: title structure, keyword frequency, bullet points, price range
4. Outputs structured competitive analysis
```

## Usage

```bash
# Analyze CSV with ASINs and titles
python3 scripts/mode3_data_analyzer.py --input /path/to/competitors.csv

# Analyze Excel file
python3 scripts/mode3_data_analyzer.py --input /path/to/competitors.xlsx

# Analyze plain ASIN list
python3 scripts/mode3_data_analyzer.py --asins "B0XXX,B0YYY,B0ZZZ"

# Full analysis with keyword extraction
python3 scripts/mode3_data_analyzer.py --input competitors.csv --full-analysis
```

## Input Formats

### CSV (minimum: ASIN column)
```csv
ASIN,Title,Price,Rating,Reviews
B0EXAMPLE1,Galaxy Projector with Remote,$19.99,4.5,1234
B0EXAMPLE2,Star Night Light for Kids,$24.99,4.3,856
```

### Excel (.xlsx)
Same columns as CSV.

### Plain ASIN List
```
B0EXAMPLE1
B0EXAMPLE2
B0EXAMPLE3
```

# Rules

🚫 **NEVER fabricate data** — ALL fields empty if not extractable
📊 **Empty string ≠ missing** — `""` means "tried, not found"; missing key means "didn't try"
⚠️ **When scraping fails**, prompt for Mode 2 or Mode 3
📎 **Every product** must have at minimum `asin` and `title` (or be omitted)
🔴 **If ALL modes fail**, return error with clear reason, never fake data
