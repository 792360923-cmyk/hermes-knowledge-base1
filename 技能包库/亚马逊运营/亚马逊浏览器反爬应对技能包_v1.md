# Amazon Browser Workarounds

## Entry-Point Hierarchy

Amazon pages differ in bot-tolerance. Prefer in this order:

| Priority | Page Type | Reliability | Example |
|----------|-----------|-------------|---------|
| 1 | **BSR / Best Sellers** | High | `/gp/bestsellers/hi/3736651/` |
| 2 | **Product page** (after bypass) | Medium | `/dp/B0H7JJB4YD` |
| 3 | **Search results** (`/s?k=`) | Low — often blocked | `/s?k=galaxy+projector` |

When search pages return "Sorry! Something went wrong!", navigate to a BSR page first (almost always loads), then use the BSR page's search bar to type and submit queries.

## BSR Page ASIN Extraction

BSR pages are JS-rendered — `data-asin` attributes and standard `<a>` tags are often absent from the initial DOM. This JavaScript via `browser_console` works consistently:

```javascript
(() => {
  const asins = [];
  document.querySelectorAll('[class*="zg-item"], [class*="p13n"], [id*="p13n"]')
    .forEach(c => {
      c.querySelectorAll('a[href*="/dp/"]').forEach(l => {
        const m = l.href.match(/\/dp\/([A-Z0-9]{10})/);
        if (m && !asins.includes(m[1])) asins.push(m[1]);
      });
    });
  return {count: asins.length, asins};
})()
```

## BSR Pagination Quirk

Amazon BSR pages show **30 items per page** with non-contiguous numbering:
- Page 1: BSR ranks #1–30
- Page 2: BSR ranks #51–80
- Ranks #31–50 are not directly accessible via standard pagination.

To collect 50+ ASINs from one category, combine page 1 + page 2 = 60 ASINs.

## "Continue Shopping" Blocker

Navigating directly to `/dp/ASIN` may show a blocker page. Workaround:
1. Click "Continue shopping" button
2. Re-navigate to the same ASIN URL
3. Second navigation typically succeeds

## Amazon Search via BSR Proxy

When `/s?k=keyword` fails:
1. `browser_navigate` to a BSR page
2. `browser_type` on the search box
3. `browser_click` on "Go"
4. Extract ASINs from results

## execute_code Variable Persistence

Variables from one `execute_code` call do **not** persist to the next. Each runs in a fresh Python process. Re-read data files in each call rather than relying on prior state.
