# 卖家精灵 + Amazon 验证工作流

## 适用场景
用卖家精灵导出的 Excel 做 Amazon 产品调研（BSR前50/100分析），需要结合 Amazon 详情页和 Alexa 验证参数后生成分析 Excel。

## 数据读取
卖家精灵导出的 .xlsx 文件用 openpyxl 直接 `load_workbook` 可能因 XML 兼容性问题失败（`ValueError: Unable to read workbook`）。

**解决方案**：
```bash
pip install xlsx2csv
xlsx2csv input.xlsx /tmp/output.csv
```
然后用 Python `csv.DictReader` 读取。CSV 的「详细参数」列是 `Key: value | Key: value` 格式，`split(' | ')` 解析。

## 字段归一化
卖家精灵「详细参数」列的值不统一，需要归一化：
- `Power Source`：`ac` → `Corded Electric`、`Hand_powered` → `手动`、`Battery Powered (Battery and Charger not Included)` → `Battery Powered`
- `Voltage`：带 `_of_direct_current` / `_of_alternating_current` 后缀的需 strip
- `Form Factor`：`Handheld` / `Backpack` / `Ergonomic` 等

## 图片下载
- 优先用 `images-na.ssl-images-amazon.com` 的 URL（比 `m.media-amazon.com` 更稳定）
- 下载后检查 `os.path.getsize() > 1000`，过滤空文件（m.media-amazon.com 偶返11B空图）
- 主图ID提取：`re.search(r'images/I/([^._]+)', url)`，去掉 `+` 号

## 中国卖家Listing特征（常见坑）
工具/户外类目的中国卖家Listing：
- **经常没有结构化参数表**：`#productOverview_feature_div` 和 `#productDetails_techSpec_section_1` 可能为空
- 依赖五点/A+图片展示参数，但五点里也常不写具体数值（CFM/MPH/噪音dB/电池容量Ah）
- **Alexa会确认"Not specified on product page"**：此时字段标「未标注」，不能编造

## Alexa验证（强制步骤）
用户明确要求：**不能只看卖家精灵数据就出表**。竞对验证必须包含Alexa环节：
1. 登录Lisa账号（`browser_navigate` → `https://www.amazon.com/gp/sign-in.html` → 792360923@qq.com / Feiye123）
2. 进产品页 → 点「Open Alexa panel」
3. 用 `browser_console` 的 React setter 输入问题（英文）
4. 读回答，标注"Alexa来源"或"未标注"

详见 `amazon-alexa-rufus-query` skill。

## 汇率
每次做表前查当日 USD/CNY 汇率：
```bash
curl -s "https://api.exchangerate-api.com/v4/latest/USD" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['rates']['CNY'])"
```
表格标题标注"汇率：1 USD = X.XX CNY (YYYY-MM-DD)"。

## 结论输出格式
必须包含：
1. 款式/类型分布（数量+占比）
2. 售价因素分析（用实际数据支撑）
3. 市场演变趋势（按上架年份×功能维度交叉分析，渗透率阶段判断）
4. 配件/功能差异化
5. 切入方向 + 做/不做决策
6. 差评驱动的切入点分析（用户特别要求）
