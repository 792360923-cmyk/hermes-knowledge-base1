# 飞书机器人集成 — WebSocket 长连接

## 触发条件

- 用户说"配置飞书""接入飞书""飞书机器人""飞书长连接"
- 需要在飞书上收发消息并接入 Hermes

## 前置条件

- 飞书开发者后台创建自建应用（企业自建应用）
- 获取 App ID + App Secret
- 应用已发布（版本管理与发布 → 创建版本 → 申请发布）

## 配置步骤

### 1. 飞书开发者后台配置

1. **添加应用能力** → 开启「机器人」
2. **权限管理** → 开通：
   - `im:message`（获取消息）
   - `im:message:send_as_bot`（发送消息）
3. **事件与回调** → 事件配置 → 订阅方式选「长连接」
4. **添加事件** → 搜索添加 `im.message.receive_v1`（接收消息 v2.0）
5. **版本管理与发布** → 创建版本（如 1.0.0）→ 申请发布
6. **群聊添加机器人** → 飞书群设置 → 群机器人 → 添加

### 2. 安装 Python SDK

```bash
pip3 install lark-oapi
```

### 3. 长连接客户端代码

关键点：飞书 Python SDK 的长连接 API 路径：

```python
from lark_oapi.ws import Client
from lark_oapi.event.dispatcher_handler import EventDispatcherHandlerBuilder
from lark_oapi.api.im.v1 import P2ImMessageReceiveV1

# NOTE: 事件处理器用空字符串初始化 (不是 app_id/app_secret)
event_handler = (
    EventDispatcherHandlerBuilder("", "")
    .register_p2_im_message_receive_v1(your_callback)
    .build()
)

ws = lark.ws.Client(
    app_id=APP_ID,
    app_secret=APP_SECRET,
    event_handler=event_handler,
    auto_reconnect=True
)
ws.start()
```

消息回复用 REST API（比 SDK 更可靠）：

```python
import requests, json

def reply_msg(msg_id, text):
    token = get_token()  # tenant_access_token via internal auth
    content = json.dumps({"text": text})
    r = requests.post(
        f"https://open.feishu.cn/open-apis/im/v1/messages/{msg_id}/reply",
        headers={"Authorization": f"Bearer {token}", "Content-Type": "application/json"},
        json={"content": content, "msg_type": "text"}, timeout=10
    )
```

## 常见陷阱

### SDK 回复 API 命名空间错误
- ❌ `client.im.message.reply()` — 不存在
- ❌ `client.im.v1.message.reply()` — 模块路径对但 ReplyMessageRequest 导入路径不对
- ✅ 直接用 REST API `POST /im/v1/messages/{msg_id}/reply` — 最可靠

### WebSocket 404 错误
- 原因1：应用未发布（版本管理与发布 → 创建版本 → 发布）
- 原因2：权限未开通（im:message + im:message:send_as_bot）
- 原因3：事件 `im.message.receive_v1` 未添加
- 原因4：使用了错误的 WebSocket URL（SDK 会自动发现正确的地址）

### 消息回复静默失败
- 消息类型必须为 `text`，content 必须是 JSON 字符串 `{"text": "..."}`
- token 用 tenant_access_token（internal 模式），不用 app_access_token

## Hermes 集成

将飞书消息接入 Hermes 的最简方案：`subprocess` 调用本地脚本生成回复。

```python
def process_message(text):
    result = subprocess.run(
        ["python3", "/root/.hermes/scripts/feishu_reply.py", text],
        capture_output=True, text=True, timeout=10
    )
    return result.stdout.strip()
```

回复脚本 `/root/.hermes/scripts/feishu_reply.py` 按关键词匹配生成智能中文回复。

## 日志监控

飞书长连接客户端日志格式：
```
[Lark] [INFO] connected to wss://msg-frontier.feishu.cn/ws/v2?... [conn_id=...]
[飞书] {sender}... → {text}
[回复] OK: {text}
```

`im.chat.access_event.bot_p2p_chat_entered_v1` 和 `im.message.message_read_v1` 错误可忽略（未注册这些事件的处理器，不影响消息收发）。
